## 🎯 Objetivo da Atividade

O objetivo desta atividade é configurar o ambiente de desenvolvimento com Dart/Flutter e criar um programa simples que exiba a mensagem "Hello World", garantindo que tudo está funcionando corretamente.

## 🚀 Como Executar o Programa

Siga os passos abaixo para rodar o projeto:

1. **Verificar instalação do Flutter/Dart:**
   No terminal, execute:

   ```bash
   flutter --version
   ```

2. **Executar o arquivo:**
   Rode o seguinte comando:

   ```bash
   dart lib/trabalho_1/main.dart
   ```

## 🖥️ Saída Esperada

Ao executar o programa, o terminal deverá exibir:

```text
Hello World!
```
