## Objetivo da Atividade
O objetivo desta atividade é configurar o ambiente de desenvolvimento Dart e criar um programa simples que exiba a mensagem "Hello World" no terminal, garantindo que a linguagem está funcionando corretamente.

## Instruções para Execução

Para rodar este programa, siga os passos abaixo:

1. **Verificar se o Dart está instalado:**
   No terminal, execute:
   ```bash
   dart --version
   ```

2. **Executar o programa:**
   Utilize o comando:
   ```bash
   dart lib/trabalho_1/trabalho_1_victor/main_t1_victor.dart
   ```

---

## Exemplo de Saída no Terminal

Ao executar o comando acima, será exibido:

```text
Hello World!
```
