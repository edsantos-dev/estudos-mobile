## 🎯 Objetivo da Atividade
O objetivo desta atividade é realizar a configuração inicial do ambiente de desenvolvimento Flutter/Dart e criar uma aplicação básica que exiba a mensagem "Hello World" no terminal ou na interface, validando que o framework está instalado corretamente.

## 🚀 Instruções para Execução

Para rodar este programa, segue os passos abaixo:

1.  **Certificar-se de ter o Flutter instalado:**
    No terminal, digita `flutter --version` para verificar.

2.  **Executa o programa:**
    Pode rodar o programa usando o comando:
    ```bash
    dart lib/trabalho_1/trabalho_1_eduardo/main_t1_eduardo.dart
    ```
