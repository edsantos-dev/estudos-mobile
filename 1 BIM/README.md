# Atividades Avaliativas

Este repositório contém todas as atividades avaliativas desenvolvidas para a disciplina de Progamação Mobile, com entrega programada para o dia **13/04**.

## 📂 Estrutura do Repositório

O projeto está organizado de forma numerada. 
As pastas foram renomeadas de acordo com a numeração de cada atividade para facilitar a navegação e correção:

* **lib/**
    * **trabalho_1/**: Introdução ao Dart e configuração de ambiente.
        * `trabalho_1_eduardo/`
        * `trabalho_1_felipe/`
        * `trabalho_1_lucas/`
        * `trabalho_1_victor/`
    * **trabalho_2/**: CRUD de biblioteca em OO.
    * **trabalho_3/**: Calculadora em Flutter utilizando componentização.
    * **trabalho_4/**: Aplicação de Lista de Tarefas com Gestão de Estado.


## 🚀 Como Executar

Como o repositório contém múltiplos aplicativos dentro de um único projeto Flutter, siga as instruções abaixo:

### Via Visual Studio Code (Recomendado)
1. Vá até a aba **Run and Debug** (`Ctrl + Shift + D`).
2. No menu suspenso no topo, selecione a configuração correspondente ao trabalho (ex: `Trabalho 2: CRUD Biblioteca`).
3. Pressione **F5**.

### Via Terminal
Para rodar um trabalho específico diretamente pelo terminal, utilize o comando apontando para o arquivo desejado:
```bash
# Exemplo para rodar o Trabalho 1 do Eduardo
dart lib/trabalho_1/trabalho_1_eduardo/main.dart
```
